This folder contains ten candidate level configurations used by the prototype runtime.

Files are plain JSON LevelDefinition entries. LevelCatalog discovers level-* assets, validates them, rejects duplicate IDs and orders by asset name. This README is not a level.

The current startingPieces arrays are empty: gem openings are deterministic generated layouts, not handcrafted teaching layouts. Crystal patterns and goals are configured explicitly. Use Gemforge > Level Workshop to bake/paint openings and validate changes. Playtest the tutorial sequence and completion paths before marking P2.7 done.
