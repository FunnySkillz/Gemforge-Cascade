# Gemforge Cascade

A Unity match-3 prototype with a cooler gem-forging theme: swap adjacent gems, create lines of three or more, score cascades, and keep the board flowing.

## Open

Open this folder in Unity 2022.3 LTS or newer.

If `Assets/Scenes/Main.unity` is not present yet, run:

`Gemforge > Build Main Scene`

Then press Play.

## Current Prototype

- 8x8 generated gem board
- Adjacent swap input
- Match detection for rows and columns
- Invalid swap rollback
- Gravity, refill, and cascade scoring
- Basic HUD for score and moves
